# Directives du porteur du projet

Chaque fichier de ce dossier est une directive pour une partie de l'application. Elles complètent le
cahier des charges (`docs/CAHIER_DES_CHARGES.md`) et les ajouts (`AJOUTS_CAHIER_DES_CHARGES.md`).

- `00-regles-communes.md` s'applique à TOUTES les pages, sans exception.
- Les fichiers suivants sont numérotés dans l'ordre où ils ont été donnés.
- En cas de contradiction, la directive la plus récente l'emporte pour la partie qu'elle concerne.
- Les modèles visuels cités sont dans `docs/references-ui/` : ce sont des sources d'inspiration à adapter.

Pour ajouter une directive : créer `05-nom-de-la-partie.md` (texte libre), et si besoin un dossier
`docs/references-ui/05-nom-de-la-partie/` avec le code du modèle à suivre.
